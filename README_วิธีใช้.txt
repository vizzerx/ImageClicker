โปรแกรมนี้ทำอะไร
----------------
เฝ้าหน้าจอ พอเจอรูปที่ตรงกับตัวอย่างที่กำหนด ก็เลื่อนเมาส์ไปคลิกให้
อัตโนมัติ ทำเป็นลำดับขั้นได้ มี "กลุ่มยืดหยุ่น" และบันทึกเป็นพรีเซ็ต
เพื่อเอาไปใช้เครื่องอื่นได้โดยไม่ต้องตั้งใหม่


ติดตั้งครั้งแรก (Windows)
-------------------------
1. ติดตั้ง Python จาก  https://www.python.org/downloads/
   ***ตอนติดตั้งให้ติ๊กถูกช่อง "Add Python to PATH"*** สำคัญมาก
2. เอาไฟล์ image_clicker.py, requirements.txt, run_windows.bat
   ไว้โฟลเดอร์เดียวกัน
3. ดับเบิลคลิก run_windows.bat (ครั้งแรกจะติดตั้งตัวช่วยให้เอง)

เช็กว่ามี Python ไหม: เปิด cmd พิมพ์  py --version


แนวคิดหลัก : ขั้นตอน + ชนิดของขั้น
----------------------------------
แต่ละ "ขั้น" = รูป 1 รูปที่จะตามหา + จำนวนคลิก + ชนิด
ชนิดของขั้นมี 2 แบบ:
  • ลำดับ    : ต้องเจอขั้นนี้ก่อน คลิกแล้วจึงไปขั้นถัดไป (เป๊ะตามคิว)
  • ยืดหยุ่น ★ : ขั้นยืดหยุ่นที่อยู่ "ติดกัน" จะรวมเป็นกลุ่มเดียว
               ในกลุ่มนี้ เจออันไหนก่อนคลิกอันนั้น ไม่ต้องรอตามคิว
               ถ้าเจอพร้อมกันหลายอัน จะเลือกอันที่อยู่บนสุดก่อน (= สำคัญสุด)

ตัวอย่าง:
  1. กดเริ่ม            (ลำดับ)
  2. ปิดป๊อปอัป A       (ยืดหยุ่น) ┐ สองอันนี้รวมเป็นกลุ่ม
  3. ปิดป๊อปอัป B       (ยืดหยุ่น) ┘ อันไหนเด้งก่อนก็ปิดก่อน
  4. กดยืนยัน          (ลำดับ)
=> ทำขั้น 1 ก่อน, จากนั้นปิดป๊อปอัปอันไหนเจอก่อนก็ได้ (A หรือ B),
   ปิดครบทั้งคู่แล้วค่อยไปขั้น 4

นอกจากนี้ แต่ละขั้นยังมี "ชนิดการหา" อีกแบบ นอกเหนือจากลำดับ/ยืดหยุ่น
ด้านบน (ดูหัวข้อ "ขั้นตำแหน่งตายตัว" ด้านล่าง) คือขั้นแบบจับคู่รูป (ปกติ)
กับขั้นแบบคลิกพิกัดตายตัว — ใช้ผสมกันในขั้นตอนเดียวกันได้


ขั้นตำแหน่งตายตัว (คลิกพิกัดจอ ไม่ต้องจับคู่รูป)
--------------------------------------------------
ปกติโปรแกรมจะหา "รูป" ที่ตรงกับตัวอย่างก่อนคลิก แต่บางปุ่มในเกม
ตำแหน่งอยู่ที่เดิมเสมอ ทว่าหน้าตาเปลี่ยนไปมา เช่น ปุ่มมีตัวเลขกำกับ
(จำนวนของ, ราคา, เวลานับถอยหลัง) ทำให้จับคู่รูปไม่ติดทุกครั้ง

วิธีใช้:
1. กด "จับตำแหน่งตายตัว" แล้วลากครอบพื้นที่ปุ่มนั้น (ลากเหมือนจับภาพปกติ
   แต่โปรแกรมจะจำแค่ "พิกัดกึ่งกลาง" ของกรอบที่ลาก ไม่ได้เก็บรูปไว้)
2. ตั้งชื่อขั้น แล้วขั้นนี้จะถูกเพิ่มเข้าไปในตารางขั้นตอน มีป้าย "[ตำแหน่ง]"
   นำหน้าชื่อ และคอลัมน์ "ตัวเลือกเพิ่ม" จะโชว์พิกัดที่บันทึกไว้ เช่น (540,320)
3. ใช้งานร่วมกับขั้นแบบรูปภาพได้ตามปกติ — จัดลำดับ ตั้งยืดหยุ่น ตั้งจำนวนคลิก
   หรือคุณสมบัติอื่น ๆ ได้เหมือนขั้นทั่วไปทุกอย่าง

ข้อควรรู้:
• ขั้นชนิดนี้จะ "เจอ" ทันทีเสมอ ไม่ต้องรอสแกนหารูป จึงคลิกได้เร็วกว่า
• คลิกที่พิกัดที่บันทึกไว้แบบเป๊ะ ๆ ทุกครั้ง ไม่สุ่มตำแหน่ง แม้เปิด
  "สุ่มตำแหน่งคลิกในรูป" ไว้ก็ตาม (ฟีเจอร์สุ่มมีผลเฉพาะขั้นแบบรูปภาพ)
• เหมาะกับปุ่มที่ตำแหน่งคงที่ 100% เท่านั้น — ถ้า UI เกมขยับตำแหน่งปุ่ม
  (เช่น จอปรับขนาดหน้าต่างได้ หรือ layout เปลี่ยนตามเนื้อหา) ให้ใช้ขั้น
  แบบจับภาพปกติแทน


ขั้นตอนการใช้งาน
----------------
1) เพิ่มขั้น: กด "จับภาพจากจอ" แล้วลากครอบรูป  (หรือ "เพิ่มจากไฟล์"
   หรือ "จับตำแหน่งตายตัว" สำหรับปุ่มที่ตำแหน่งคงที่ — ดูหัวข้อด้านบน)
2) จัดลำดับ: เลือกขั้นแล้วกดปุ่ม ▲ / ▼
3) ตั้งยืดหยุ่น: เลือกขั้นแล้วกด "สลับ ลำดับ/ยืดหยุ่น"
   (ขั้นยืดหยุ่นที่อยู่ติดกันจะถือเป็นกลุ่มเดียวโดยอัตโนมัติ)
4) จำนวนคลิก: ตั้งในช่องล่าง แล้วกด "ใช้กับขั้นที่เลือก"
5) เลือกโหมด (แถบสลับด้านบน):
   • ตามลำดับ (มีกลุ่มยืดหยุ่น) : ทำตามคิว + รองรับกลุ่มยืดหยุ่น
   • สแกนทั้งหมด               : รอบเดียวเจอรูปไหนก็คลิกหมด
   • ติ๊ก "ทำซ้ำวนลูป" ถ้าอยากให้ทำวนไปเรื่อย ๆ
6) ตั้งค่า: ความแม่นยำ (คลิกผิด=เพิ่ม / หาไม่เจอ=ลด),
   หน่วงหลังคลิก, รอแต่ละขั้นไม่เกินกี่วินาที ฯลฯ
7) กด "เริ่มทำงาน" (หรือ F8)


ฟีเจอร์ขั้นสูง (เฉพาะโหมด "ตามลำดับ")
--------------------------------------
** ใช้กับโหมด "ตามลำดับ" เท่านั้น (โหมด "สแกนทั้งหมด" ไม่เกี่ยว) **

เลือกขั้นใดขั้นหนึ่งในตาราง ส่วน "คุณสมบัติของขั้นที่เลือก" ด้านล่าง
จะโหลดค่าของขั้นนั้นขึ้นมาให้แก้ แก้เสร็จกด "บันทึกคุณสมบัติลงขั้นที่เลือก"
(ทุกช่องปล่อยว่างไว้ = ใช้ค่ารวมที่ตั้งในแผง "ตั้งค่า")

1) ลองใหม่ (Retry)
   - ตั้งค่ารวมที่ "ตั้งค่า > [ลำดับ] ลองใหม่หากไม่สำเร็จ (ครั้ง)"
     ตัวอย่าง: ใส่ 3 = หาไม่เจอแล้วลองใหม่ได้อีก 3 ครั้งก่อนข้าม
   - หรือกำหนดเฉพาะขั้นในช่อง "ลองใหม่ (ครั้ง, ว่าง=รวม)"
   - การ "ลองใหม่" 1 ครั้ง = รอจนหมดเวลา (timeout) ของครั้งนั้นแล้วเริ่มนับใหม่
   - ใช้ได้ทั้งขั้นลำดับเดี่ยว และขั้นในกลุ่มยืดหยุ่น

2) กำหนดเวลาของแต่ละขั้น (เลือกได้ / ไม่เลือก = ใช้ค่ารวม)
   - "หน่วงหลังคลิก (วิ)" : ระยะพักหลังคลิกขั้นนี้ (ว่าง = ใช้ค่ารวม)
   - "รอไม่เกิน (วิ)"     : เวลาที่จะรอหารูปของขั้นนี้ ก่อนถือว่าล้มเหลว
                           ใส่ 0 = รอตลอดไป (ว่าง = ใช้ค่ารวม)
   - ทั้งคู่ปล่อยว่างไว้ = ใช้ค่าจากแผง "ตั้งค่า" ตามปกติ

3) ทำต่อเมื่อขั้นก่อนหน้าสำเร็จ
   - ติ๊ก "ทำต่อเมื่อขั้นก่อนหน้าสำเร็จ (ข้ามถ้าก่อนหน้าล้มเหลว)"
   - เมื่อเปิดไว้ ขั้นนี้จะถูกข้ามทันที ถ้าขั้นก่อนหน้า "ล้มเหลว"
     (คือหาไม่เจอหลังหมดเวลา + ลองใหม่ครบทุกครั้ง)
   - เหมาะกับขั้นที่ "ต้องมีขั้นก่อนหน้าสำเร็จก่อน" เช่น กดยืนยัน
     หลังปิดป๊อปอัป — ถ้าปิดป๊อปอัปไม่สำเร็จ ก็ไม่ต้องไปกดยืนยัน
   - ผลลัพธ์ "ล้มเหลว" จะทำงานต่อไปทีละขั้น (cascade) คือขั้นที่ตั้ง
     ข้อนี้ไว้และอยู่หลังขั้นที่ล้มเหลว จะถูกข้ามไปด้วยจนกว่าจะเจอขั้น
     ที่สำเร็จ (หรือเริ่มรอบใหม่ ถ้าเปิดวนลูปไว้)

4) ไม่ทำซ้ำหลังสำเร็จ (Cooldown)
   - ตั้งค่ารวมที่ "ตั้งค่า > [ลำดับ] ไม่ทำซ้ำหลังสำเร็จ (วิ, 0=ปิด)"
     ตัวอย่าง: ใส่ 30 = หลังจากคลิกขั้นนี้สำเร็จแล้ว จะข้ามขั้นนี้ไป
     ใน 30 วินาทีถัดไป (มีประโยชน์ในโหมดวนลูป)
   - หรือกำหนดเฉพาะขั้นในช่อง "ไม่ทำซ้ำหลังสำเร็จ (วิ, ว่าง=รวม)"
   - ค่า 0 หรือช่องว่าง = ปิดฟีเจอร์นี้ (ทำขั้นนั้นได้ทุกรอบ)
   - เมื่อขั้นอยู่ใน cooldown จะข้ามไป และถือว่า "สำเร็จ"
     (ไม่ทำให้ขั้นถัดไปที่ตั้ง require_prev ถูกข้ามด้วย)


บันทึกผลลัพธ์การเล่น (OCR Coins/XP)
------------------------------------
ฟีเจอร์นี้ใช้ได้เฉพาะโหมด "ตามลำดับ" — บันทึกทุกรอบที่เล่นจบ
เป็นตาราง (Round, เวลาเริ่ม, เวลาจบ, เวลาที่ใช้, Coins, XP)
และเซฟลงไฟล์ .csv ให้อัตโนมัติในโฟลเดอร์ "results"

วิธีใช้:
1. ติดตั้งโปรแกรม Tesseract-OCR (ตัวอ่านตัวเลขจากภาพ) บน Windows:
   ดาวน์โหลดตัวติดตั้งจาก https://github.com/UB-Mannheim/tesseract/wiki
   ติดตั้งแบบค่าเริ่มต้นได้เลย (ปกติจะลงที่
   C:\Program Files\Tesseract-OCR\tesseract.exe ซึ่งโปรแกรมจะหาเจอเอง)
2. ในการ์ด "บันทึกผลลัพธ์การเล่น" ติ๊กเปิดใช้งาน
3. กด "เลือกพื้นที่ Coins" แล้วลากครอบเฉพาะตัวเลข Coins บนหน้าจอ
   ทำแบบเดียวกันกับ "เลือกพื้นที่ XP"
4. ไปที่ขั้นตอนที่แสดง "หน้าผลลัพธ์" (เช่นขั้นที่กดปุ่ม OK ปิดหน้าผลลัพธ์)
   เลือกขั้นนั้นในตาราง "ขั้นตอน" แล้วติ๊ก
   "จับผลลัพธ์ (OCR Coins/XP) ตอนเจอขั้นนี้" ในช่องคุณสมบัติของขั้น
   จากนั้นกด "บันทึกคุณสมบัติลงขั้นที่เลือก"
5. กด "เริ่มทำงาน" ตามปกติ — ทุกครั้งที่เจอขั้นนั้น โปรแกรมจะจับภาพ
   ตัวเลข Coins/XP ก่อนคลิก แล้วบันทึกเป็น 1 แถวในตาราง + ไฟล์ CSV

กด "ส่งออกตาราง" เพื่อบันทึกสำเนาเป็น .csv / .json / .txt ที่อื่นได้
กด "ล้างตาราง" เพื่อล้างเฉพาะที่แสดงในหน้าจอ (ไฟล์ CSV ที่บันทึกแล้วไม่หาย)


พรีเซ็ต (ทำให้ที่บ้านไม่ต้องตั้งเอง)
------------------------------------
• "บันทึกพรีเซ็ต"  : เก็บทุกอย่าง (รูป + ลำดับ + ชนิด + ค่า) ลงไฟล์เดียว
  ฝังรูปไว้ในไฟล์แล้ว คัดลอกไปเครื่องอื่น "เปิดพรีเซ็ต" ได้เลย
• "ตั้งเป็นค่าเริ่มต้น" : เซฟเป็น default_preset.json ข้างโปรแกรม
  -> ครั้งต่อไปเปิดโปรแกรมจะโหลดให้อัตโนมัติ

ส่งให้ที่บ้านแบบไม่ต้องตั้งอะไร:
  1. คุณตั้งค่า + เพิ่มขั้นให้เสร็จที่เครื่องคุณ
  2. กด "ตั้งเป็นค่าเริ่มต้น"
  3. ส่งทั้งโฟลเดอร์ (รวม default_preset.json) ให้ที่บ้าน
  4. ที่บ้านเปิด run_windows.bat แล้วกด "เริ่มทำงาน" ได้เลย


หยุด / หยุดฉุกเฉิน
------------------
• กดปุ่ม "หยุด" หรือ F8
• ฉุกเฉิน: สะบัดเมาส์ไปชนมุมซ้ายบนสุดของจอ -> หยุดทันที


เคล็ดลับ
--------
• "สุ่มตำแหน่งคลิกในรูป" : เปิดไว้จะคลิกแบบสุ่มจุดภายในกรอบรูปที่เจอ
  (ไม่ลงกึ่งกลางเป๊ะทุกครั้ง) กันการคลิกซ้ำจุดเดิม ปรับ "ขอบเขตการสุ่ม %"
  ได้ — ค่ามากยิ่งกระจายกว้าง (แนะนำ 50-70), 0 = คลิกกึ่งกลางเป๊ะ
• จับภาพให้ครอบเฉพาะส่วนที่เป็นเอกลักษณ์ อย่าติดพื้นหลังที่เปลี่ยนไปมา
• จอความละเอียดสูงแล้วคลิกไม่ตรง ให้ตั้ง Display scale เป็น 100%
• รูปบนจอขนาดไม่เท่าตัวอย่าง ให้เปิด "ทนต่อรูปขนาดต่างกัน"
• ใช้กับงานช่วยเหลือส่วนตัว/ที่บ้านที่ถูกต้องเท่านั้น
